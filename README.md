# InfoDrogues API

REST API serving reference data on psychoactive substances — effects, risks,
danger and addiction ratings — for harm-reduction and prevention tools.

It powers [NoHigh](https://github.com/Copni/NoHigh), the React client built
alongside it.

The query interface deliberately mirrors [OMDb](https://www.omdbapi.com/):
search by exact title, by identifier, or by partial match, with the same
parameter names. Anyone who has used OMDb can query this API without reading the
documentation.

## Endpoints

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/` | Service banner |
| `GET` | `/drug?i={id}` | Look up one substance by identifier |
| `GET` | `/drug?t={name}` | Look up one substance by exact name |
| `GET` | `/drug?s={term}&page={n}` | Partial-match search, paginated |

`?s=` returns an OMDb-shaped envelope:

```json
{
  "Search": [ ... ],
  "totalResults": 3,
  "Response": "True"
}
```

`?i=` and `?t=` return a single substance object directly.

## Authentication

Every `/drug` request requires a bearer token:

```http
Authorization: Bearer <your-key>
```

A missing or incorrect token returns `401`.

## Data model

```json
{
  "id": "D001",
  "nom": "...",
  "type": "Psychotrope",
  "molecule": "THC, CBD",
  "effet": "...",
  "risque": "...",
  "prix": "≈ 10 €/g",
  "dangerosite": 4,
  "addictif": 3,
  "poster": "https://..."
}
```

`dangerosite` and `addictif` are ordinal ratings from 1 to 5, which lets a client
sort or colour-code results without parsing free text.

## Status codes

| Code | Condition |
| --- | --- |
| `200` | Match found |
| `400` | No search parameter supplied |
| `401` | Missing or invalid bearer token |
| `404` | No substance matches the given id or exact name |

## Running it

```bash
pip install -r requirements.txt
cp .env.example .env          # set API_KEY
uvicorn main:app --reload
```

Interactive documentation is generated by FastAPI at `/docs`, and the OpenAPI
schema at `/openapi.json`.

## Configuration

| Variable | Purpose |
| --- | --- |
| `API_KEY` | Bearer token accepted by `/drug` |

The key is read from the environment at startup. It must never be committed —
`.env` belongs in `.gitignore`, and only `.env.example` is versioned.

## Design notes

- **OMDb-compatible parameters.** Reusing a well-known contract instead of
  inventing one means the client code is almost identical to code written
  against OMDb, which is exactly what the companion project needed.
- **Three distinct lookup modes.** Exact match and id lookup return a bare
  object because the caller expects one result; partial search returns an
  envelope with a total count because the caller expects to paginate.
- **CORS** is enabled so that browser clients can call the API directly from a
  different origin.
